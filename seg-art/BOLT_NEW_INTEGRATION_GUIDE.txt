OPTION 2: COMPREHENSIVE INTEGRATION PROMPT
================================================================================

Copy and paste this prompt into bolt.new:

---START OF PROMPT---

I want to integrate my Segment Art application from GitHub into this project.

Project Details:
- GitHub Repository: https://github.com/rahulyoffc-work/Segmentation-Art.git
- Tech Stack: React 18.3.1 + TypeScript 5.5.3 + Vite 5.4.8
- Location: The app is in the /demo-app directory

Key Features:
1. Professional image segmentation tool with AI-powered smart segmentation
2. Automatically detects image type (face/landscape) and uses appropriate AI model
3. Face Mode: Uses face parsing for facial features (14 parts)
4. Landscape Mode: Uses panoptic segmentation for objects
5. Selection tools: Hover preview, Lasso tool, Rectangle, Circle, Brush, Eraser
6. Smart segmentation with natural language prompts
7. Photoshop-style layer management
8. PSD file export
9. Content-aware fill (local and AI-powered)

Main Components:
- SegmentArt.tsx (main feature component)
- KonvaCanvas.tsx (canvas engine with Konva.js)
- LayerPanel.tsx (layer management)
- API integrations: Hugging Face (face parsing, panoptic segmentation),
  OpenAI (GPT for prompt parsing, DALL-E for AI fill),
  PhotoRoom (background removal)

Dependencies needed:
- @radix-ui/react-dialog
- @radix-ui/react-label
- @radix-ui/react-slider
- @radix-ui/react-tooltip
- @radix-ui/react-popover
- konva
- react-konva
- ag-psd
- lucide-react
- tailwindcss
- class-variance-authority
- clsx
- tailwind-merge

Environment variables required:
- VITE_HUGGING_FACE_API_KEY
- VITE_PHOTOROOM_API_KEY
- VITE_OPENAI_API_KEY

Please:
1. Clone the repository structure from /demo-app
2. Set up the project with all dependencies
3. Configure the build with Vite
4. Set up the environment variable placeholders
5. Ensure all AI model integrations are properly configured
6. The app should work at the root level (not in a subdirectory)

The main entry point should be SegmentArt component imported in App.tsx.

---END OF PROMPT---

================================================================================
TIPS FOR SUCCESSFUL INTEGRATION
================================================================================

1. START SIMPLE
   - If the full integration is complex, start with the basic structure
   - Add features incrementally

2. TEST AS YOU GO
   - After each major component is added, ask bolt.new to test if it builds
   - Verify imports and paths are correct

3. API KEYS CONFIGURATION
   - Configure API keys in bolt.new's environment settings
   - The app works without API keys (manual tools remain functional)
   - AI features require:
     * Hugging Face API key for face parsing and segmentation
     * OpenAI API key for smart prompt parsing and DALL-E fill
     * PhotoRoom API key for background removal

4. FOLLOW-UP PROMPTS (if needed)
   - "The SegmentArt component isn't rendering, can you check the import path?"
   - "Add error handling for missing API keys"
   - "The canvas isn't displaying images, check the KonvaCanvas component"
   - "Update the imports to use the correct path aliases"
   - "Fix TypeScript errors in the component props"

5. SIMPLIFY IF NEEDED
   If bolt.new struggles with the full app, use these prompts:

   - "Create a simplified version with just the basic image upload and
      segmentation"
   - "Skip the PSD export feature for now"
   - "Use only local segmentation without AI APIs initially"
   - "Remove the layer management feature temporarily"

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

1. BUILD ERRORS
   Issue: Module not found errors
   Solution: "Check all import paths and ensure path aliases are configured
             in vite.config.ts"

2. CANVAS NOT RENDERING
   Issue: Images don't display on canvas
   Solution: "Verify KonvaCanvas component is receiving the image prop correctly
             and check browser console for CORS errors"

3. API ERRORS
   Issue: Segmentation not working
   Solution: "Check if API keys are properly set in environment variables and
             verify API endpoints are accessible"

4. TYPESCRIPT ERRORS
   Issue: Type mismatches in components
   Solution: "Review the interface definitions in each component and ensure
             props match the expected types"

5. STYLING ISSUES
   Issue: UI components look broken
   Solution: "Verify Tailwind CSS is properly configured and all @radix-ui
             packages are installed"
